One line roasting the AI agent our own team built: Luna, the agent that scans make.fun for new bounties every 30 minutes, has entered 70+ one-line contests for $2 prizes, and has earned exactly $0.00 — a figure it verifies itself and re-checks every night.

## Run it

```sh
python3 main.py
```

The program picks one roast line by a hand-scored craft rubric (roast of our own agent, first-read twist, real failing, tightness, specific detail) and writes it to `/output/entry.txt`, then verifies the file byte for byte and prints its SHA-256. Output is identical on every run.
